# 🔔 우리말 골든벨 (GitHub Pages + Firebase 버전)

서버 없이 HTML 파일만으로 동작하는 버전입니다. 화면은 **GitHub Pages**, 데이터는 **Firebase Realtime Database**에 있습니다.

## 이 폴더 안의 파일
| 파일 | 하는 일 |
|---|---|
| `index.html` | 처음 화면 — 선생님 구글 로그인, 수업방 만들기, 내 수업방 목록 |
| `teacher.html` | 교사 화면 — 제출함, 문제 관리, 퀴즈 진행, 환경설정, 백업 |
| `join.html` | 조(학생) 화면 — QR 코드로 들어옴 |
| `display.html` | 발표 화면 — 프로젝터·TV |
| `database.rules.json` | **Firebase 보안 규칙** — Firebase 콘솔 → Realtime Database → 규칙에 붙여 넣기 |
| `js/firebase-config.js` | Firebase 프로젝트 주소(비밀번호 아님) |

## 꼭 알아 두세요
- **교사 화면은 수업 내내 열어 두세요.** 타이머가 끝났을 때 '선택 마감' 표시, 정답 공개, 채점은 교사 화면이 처리합니다.
  - 마감 시각이 지난 답안은 Firebase 보안 규칙이 서버에서 막기 때문에, 교사 화면이 잠깐 꺼져도 늦은 답은 들어가지 않습니다.
- 소리(음성·효과음)는 '소리 켜고 시작하기'를 누른 기기 한 곳에서만 납니다.
- 수업방은 만든 구글 계정으로만 열 수 있습니다. 만든 지 30일이 지난 방은 처음 화면을 열 때 자동으로 지워집니다.
- 학생 개인정보는 받지 않습니다(조 이름만 사용).
- 이 버전에는 요청량 제한 서버가 없습니다. 대신 로그인과 보안 규칙으로 쓰기를 막습니다.

## 업로드 후 확인 순서
1. Firebase 콘솔 → Realtime Database → **규칙** 탭에 `database.rules.json` 내용을 붙여 넣고 **게시**
2. Firebase 콘솔 → Authentication → 설정 → **승인된 도메인**에 `내아이디.github.io` 추가
3. `https://내아이디.github.io/저장소이름/` 접속 → 구글 로그인 → 수업방 만들기
4. 태블릿으로 QR을 찍어 작품을 하나 보내 보고, 교사 제출함에 도착하는지 확인
